# Cadastro Automático de Cursos

**Versão:** 1.2.0

**Descrição**
Automatiza o cadastro de cursos a partir de uma planilha Excel ou CSV com interface moderna e experiência aprimorada.

**Sobre**
Permite que o usuário faça o upload de arquivos `.xlsx` ou `.csv` para automatizar o lançamento de capacitações e cursos em sistemas online.
